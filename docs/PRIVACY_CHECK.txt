============

範圍：本交付包；不包含原始工作區或使用者電腦其他資料夾。

原專案發現的項目與處理

驗證
- 11 份母版已檢查未壓縮專案內容，清理前後圖中文字及數值一致。
- 11 頁均以內附 Python 完成資料寫入、OPJU 儲存與重新開啟測試。
- EXE 介面已完成內附 Python 實際出圖儲存測試。
- 已掃描程式、設定、母版、執行環境檔案及 Python 標準庫壓縮內容。
- 在上述範圍內，未發現已知使用者姓名路徑、原始實驗檔名或常見憑證格式。

保留的內容
- 母版原有範例曲線與數值：用於保留版型，沒有納入使用者新提供的實驗數據。

- 通用系統路徑與第三方編譯路徑不代表使用者私人資訊。

限制
- 掃描與 Origin 重新儲存驗證無法保證識別任意未知格式或任意私人文字。
- 使用者匯入的數據與檔名會寫入輸出的 OPJU，分享輸出前仍須自行確認。
